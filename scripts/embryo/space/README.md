# Embryo-56M

Tests and chat for [Embryo-56M](https://huggingface.co/infosave/Embryo-56M-cmf), the first experimental version of a model built entirely on the technologies of Oleg Kirichenko. Larger models for different tasks and the mechanisms for training models will follow.

The test sets are fixed-seed samples of the release gates. For each answer the page shows where it came from and why the router decided so. This Space runs on a free 2-core CPU: for GPU speed see the Measured tab. Results stay in your browser; the gateway keeps no logs of the questions.

Тесты и чат для [Embryo-56M](https://huggingface.co/infosave/Embryo-56M-cmf), первого экспериментального варианта модели, полностью основанной на технологиях Олега Кириченко. В дальнейшем выйдут более крупные модели для различных задач и механизмы обучения моделей.
