## Итог

Ни одна готовая модель на 135–360M с задачей не справляется: лучшая решает треть.

| Модель | Параметры | Верных ответов из 362 | Доля | 95 % |
|---|---|---|---|---|
| Скопировать первый пример карточки (нижняя граница) | | 16 | 4,4 % | 3–7 |
| Boris-2-Think | 144M | 21 | 5,8 % | 4–9 |
| SmolLM2-135M-Instruct | 135M | 49 | 13,5 % | 10–17 |
| SmolLM2-360M-Instruct | 362M | 126 | 34,8 % | 30–40 |
| Эталонные ответы (самопроверка оценщика) | | 362 | 100 % | |

Условия: карточка команды в контексте, два разобранных примера той же категории, жадное
декодирование, без дообучения. Команды проверялись запуском в песочнице.

Что это значит для плана:

1. **Сработал критерий этапа 0 «низко у всех».** По плану в этом случае задача упрощается
   до обучения: больше работы уходит в записи, роутер и грамматику, сети остаётся меньше.
2. **Индекс таблицы лидеров это умение не предсказывает.** Boris-2-Think, лучшая модель до 150M
   по индексу (36,05), здесь на уровне нижней границы. Его `<think>` на процедуру не переносится:
   он пытается сам ответить на вопрос вместо того, чтобы собрать команду.
3. **Размер в этом режиме важен.** В одном семействе SmolLM2 переход от 135M к 360M даёт
   13,5 → 34,8 %.
4. **Это нижняя оценка класса.** Модели не дообучались на нашем формате. Сколько даст обучение,
   этот замер не показывает.

Что стоит за числами:

- **Правилам не следует никто.** Обе SmolLM2 на все 25 задач react ответили DONE: это пять

- **100 % у SmolLM2-135M на none — не умение.** Она отвечает NONE на все 44 задачи с тремя

- **Счёт по выводу не работает:** 2–8 %.
- **SmolLM2-360M справляется, когда пример можно взять почти как есть.** Полностью верны 17 из

## Что менять в плане

Каждый вид ошибки закрывается механизмом, который в плане уже есть, но стоял позже:

| Ошибка | Чем закрыть | Где в плане |
|---|---|---|
| Другая программа, не тот раздел ОС | Карточку и пример выбирает роутер, не сеть | этап 6 → до обучения |
| Аргументы неверны, значение не подставлено | Запись хранит шаблон с типами значений; сеть под грамматикой пишет только значения | этап 6 → до обучения |
| Правила по выводу | Решение (повторить, уточнить, отдать оракулу) — отдельные подпространства роутера | часть 1 плана 03.11 |
| Счёт по выводу | Считает инструмент (`awk`, `bc`), а не сеть | новое |

После этого сети остаётся: перенести значения из запроса в шаблон и собрать два шага
в конвейер. Это заметно меньше, чем «рассуждение над карточкой» в нынешнем виде набора R.

## Чего замер не показывает

- **Дообучение.** Все три модели видели формат впервые. Прямая проверка стоит недорого
  и идёт на Маке: дообучить SmolLM2-135M и 360M на задачах, собранных из других карточек,
  и повторить замер на R. Она ответит, выучивается ли процедура в этом классе размеров.
  В рамки этапа 0 это не входило и не делалось.
- **Русский язык.** Запросы в R английские: все три модели английские.
- **Набор R собран мной** за один проход: 362 задачи, 9 категорий, карточки из tldr. Эталоны
  проверены запуском, но формулировки никто, кроме меня, не читал.

## Как мерили

- **Набор R** (`families.py`, `build_r.py`): карточки — страницы tldr-pages (CC-BY 4.0) в виде,
  в каком запись подставит их в контекст, со значениями в `{{…}}`. Набор только для оценки:
  в обучающие данные он не идёт.
- **Проверка** (`sandbox.py`, `grade.py`): 202 задачи проверяются запуском команды модели
  в одноразовом контейнере Docker без сети, от непривилегированного пользователя, и сравнением
  результата с результатом эталона. 79 задач для macOS, Windows и команд о состоянии системы —
  сравнением с допустимыми формами после нормализации. 81 задача — метка или число.
- **Запрос** (`run_model.py`): одинаковый текст задачи и два разобранных примера на карточках,
  которых в R нет. У SmolLM2 штатный чат-шаблон, у Boris-2-Think его формат с `<think>`
  и `Final answer:`.
- **Boris-2** (`boris_cached.py`): штатный код модели не держит KV-кэш, 8 задач шли 453 с.
  Инкрементный проход считает то же самое: расхождение логитов с проходом самой модели 1,3e-4,
  ни одной смены аргмакса, вывод на 8 задачах совпал побайтно, время 11 с.
- **Лицензии** проверены до загрузки: три модели Apache-2.0, tldr CC-BY 4.0. Код Boris-2
  прочитан до запуска.

## Воспроизведение

```bash
scripts/hermes-core/stage0/run.sh all
```

Шаги: `build` (набор R и самопроверка эталонов), `baselines`, `models` (три модели по очереди),
`grade`, `report` (таблица `results.md`). Нужен запущенный Docker. Каталог прогона —
`$STAGE0`, по умолчанию `~/embryo-data/hermes-core/stage0`.
