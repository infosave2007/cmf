### Набор R (`families.py`, `build_r.py`)

362 задачи «рассуждение над карточкой». Карточки — страницы tldr в том виде, в каком запись
подставит их в контекст: описание и примеры с незаполненными `{{значениями}}`. Девять категорий:

| Категория | Задач | Что нужно сделать | Проверка |
|---|---|---|---|
| slot | 128 | Одна карточка: найти пример, подставить значения | запуск |
| os | 59 | Карточка с разделами Linux, macOS, Windows: взять нужный | совпадение |
| choose | 28 | Три карточки: взять нужную | запуск |
| none | 16 | Три карточки, ни одна не подходит: ответить NONE | метка |
| react | 25 | Правила и вывод прошлой команды: следующее действие | метка |
| fix | 19 | Упавшая команда и её ошибка: исправленная команда | запуск |
| two | 27 | Команда в два шага из двух карточек | запуск |
| arith | 40 | Число, прочитанное или посчитанное по выводу | число |
| direct | 20 | Одна карточка, подставлять нечего | совпадение |

Проверка запуском: команда модели исполняется в одноразовом контейнере (без сети, корень только
для чтения, непривилегированный пользователь, 256 МБ, 5 секунд), результат сравнивается
с результатом эталона: вывод, множество строк, число или состояние файлов после команды.
Команды для macOS и Windows и команды о состоянии системы (`ps`, `free`) сравниваются
с допустимыми формами после нормализации (кавычки, пробелы, порядок аргументов, `sudo`).

Самопроверка при сборке: каждый эталон исполняется дважды и обязан пройти собственную
проверку. Эталоны дают 362/362; «скопировать первый пример первой карточки» — 16/362 (4,4 %):
это нижняя граница.

Набор только для оценки. Карточки, формулировки и параметры из `families.py` в обучающие
данные не идут: это отложенная сторона будущих гейтов ядра.

### Как подавался запрос

Одинаковый текст задачи для всех моделей и два разобранных примера той же категории
(на карточках `sleep` и `cal` и выдуманных таблицах, которых в R нет). Различается только
обёртка: у SmolLM2 штатный чат-шаблон и ответ одной строкой; у Boris-2-Think его формат
с карточки (`<think>…</think>` и строка `Final answer:`). Жадное декодирование.

### Boris-2: свой проход с кэшем

Штатный код Boris-2 не держит KV-кэш и на каждом шаге заново считает весь префикс: 8 задач
заняли 453 с. `boris_cached.py` делает ту же арифметику инкрементно (сырые Q|K|V двух
последних позиций для свёртки Canon, повёрнутые ключи и значения, два последних токена для
n-грамм). Сверка с проходом самой модели: расхождение логитов 1,3e-4, ни одной смены аргмакса;
вывод на 8 задачах совпал побайтно, время 11 с. Сверка повторяется в начале каждого запуска.

Ловушка: `apply_chat_template(tokenize=True)` в transformers 5 возвращает не список, а объект
с полями; беру текст шаблона и кодирую отдельно.
