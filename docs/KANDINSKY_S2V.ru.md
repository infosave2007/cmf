# Kandinsky S2V на cortiq

*Языки: [English](KANDINSKY_S2V.md) · **Русский** · [中文](KANDINSKY_S2V.zh.md)*

[Kandinsky S2V 1.0 Pro-distill](https://huggingface.co/kandinskylab/Kandinsky-S2V-1.0-Pro-distill-Diffusers)
превращает один опорный кадр и дорожку речи в видео с аватаром. Движется вся фигура, а
не только голова. Звук служит условием: модель его не генерирует, `cortiq` записывает
вашу дорожку в выходной файл.

## Запуск

```bash
cargo install cortiq-cli
hf download infosave/Kandinsky-S2V-1.0-Pro-distill-cmf kandinsky-s2v-pro-q4tp.cmf --local-dir .
cortiq s2v --model kandinsky-s2v-pro-q4tp.cmf --image reference.png --audio speech.wav --out avatar.avi
```

На выходе MJPEG со звуком PCM в AVI, 25 кадров/с, ничего устанавливать не нужно.
Чтобы получить mp4:

```bash
ffmpeg -i avatar.avi -c:v libx264 -crf 18 -c:a aac avatar.mp4
```

| параметр | по умолчанию | значение |
|---|---|---|
| `--image` | обязателен | опорный кадр (PNG, JPEG) |
| `--audio` | обязателен | дорожка речи: WAV читается сразу, остальное через `ffmpeg` |
| `--out` | `avatar.avi` | выходной файл |
| `--prompt` | эталонный промпт | описывает движение; свой промпт загружает текстовый энкодер 7B |
| `--seed` | 5 | зерно шума |
| `--steps` | 16 | сегментов pi-Flow на чанк |
| `--chunks` | сколько нужно для дорожки | чанки по 5 с; видео обрезается по дорожке |
| `--height`, `--width` | ближайший размер серии 512 | 512×512, 768×512 или 512×768 |
| `--quality` | 92 | качество JPEG |

## Конвейер

```
речь → мел → аудиобашня → 25 токенов/с ──┐
промпт → Thinker + CLIP (для штатного    ├─ DiT, 16 сегментов на чанк ─→ декодер VAE ─→ кадры
         промпта уже в файле)            │     ↑ память FramePack предыдущего чанка
опорный кадр → энкодер VAE ──────────────┘
```

- **DiT.** 60 визуальных блоков размерности 4096, 4 блока промпта и 4 блока речи, 21B
  параметров. Чанк размера 512² — это 36736 токенов: память FramePack на трёх временных
  масштабах, опорный кадр и 32 латентных кадра.
- **pi-Flow.** Один проход предсказывает 5 значений x0 на сегменте сырого времени, и ОДУ
  интегрируется по ним без новых проходов сети. Guidance уже зашит в веса.
- **VAE.** Каузальный 3-D VAE HunyuanVideo с тайлингом по времени, как в исходном классе
  по умолчанию: 5 латентных кадров через каждые 3, на стыке смешиваются 4 кадра.

## Как это работает

Веса не помещаются на карту 32 ГБ в виде плоскостей f16 (42 ГБ). Квантованные байты
контейнера лежат на карте как есть, а плоскости одного блока разворачиваются прямо перед
его запуском, поэтому q4tp требует для DiT около 14 ГБ видеопамяти. На Metal веса
остаются в отображении файла и распаковываются по мере чтения GEMM. VAE постоянно живёт
на устройстве в обоих случаях. Если устройство отказывается, `cortiq s2v` уходит на CPU,
а это часы на сегмент при 36736 токенах.

## Паритет

`scripts/s2v/oracle.py` снимает эталон по стадиям (целиком конвейер не помещается в один
процесс на карте 32 ГБ), а `cortiq s2v-check` сравнивает каждую стадию:

```bash
python scripts/s2v/oracle.py enc --image i.png --audio a.wav --chunks 1 --out enc.safetensors
cortiq s2v-check --model kandinsky-s2v-pro-q8.cmf --stage enc --oracle enc.safetensors
```

Журнал со всеми замерами: `scripts/s2v/JOURNAL_S2V_2026-11-03.md`.

## Ответственное использование

Модель оживляет реального человека по одной фотографии голосом, который может быть не его.
Используйте опорный кадр только с согласия изображённого и не выдавайте результат за
настоящую запись кого-либо.
